\# Student Management System



\## Project Description



The Student Management System is a web-based application developed using Python Flask and SQLite.



It helps manage student information such as name, email, and course.



\## Technologies Used



\- Python

\- Flask

\- SQLite

\- HTML

\- CSS



\## Features



\- Add Student

\- View Students

\- Search Students

\- Edit Student

\- Delete Student

\- Student Dashboard

\- Course Statistics



\## Project Structure



StudentManagementSystem/



\- app.py

\- students.db

\- templates/

&#x20; - index.html

&#x20; - edit.html

\- static/

&#x20; - style.css



\## How to Run



1\. Activate the virtual environment.

2\. Run `python app.py`.

3\. Open `http://127.0.0.1:5000` in a web browser.



\## Purpose



This project was created as a BCA academic project to demonstrate basic web development, database management, and Python programming skills.
